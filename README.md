#  Cargo Link — Move Cargo. Move Business.

##  Project Description

Cargo Link is a logistics website prototype designed to connect customers with cargo and logistics service providers in one platform.

The project aims to make it easier for customers to discover cargo services, access shipping information, explore delivery options, and find shipment-tracking resources. It also gives cargo businesses an opportunity to improve their online visibility and reach more potential customers.

Cargo Link is a front-end project developed as part of the Zindua School Web Development Module 1.

## Problem Statement

Many customers experience difficulties finding reliable cargo service providers, accessing shipping information, and keeping track of their shipments.

At the same time, some cargo businesses struggle to market their services and reach potential customers online.

Cargo Link aims to address these challenges by providing a centralized platform where customers can explore cargo services and businesses can showcase their offerings.

##  Target Users

Cargo Link is designed for:

* **Individuals:** People who need to transport packages or goods.
* **Businesses:** Companies that need cargo transportation and delivery services.
* **Cargo Companies:** Logistics providers looking to improve their online visibility.
* **Small Business Owners:** Entrepreneurs who need accessible cargo and shipping information.

##  Features

* **Homepage:** Introduces Cargo Link and its main services.
* **Cargo Tracking:** Provides a form for users to enter their shipment tracking number.
* **Shipping Calculator:** Allows users to enter shipment details to support shipping cost estimation.
* **Services Page:** Presents the cargo and logistics services available through the platform.
* **How It Works:** Explains the process of discovering services and managing cargo shipments.
* **Partners Page:** Introduces opportunities for cargo businesses to connect with the platform.
* **FAQ Page:** Provides answers to common questions about Cargo Link.
* **Contact Page:** Displays contact information and a form for submitting inquiries.
* **Responsive Design:** Uses CSS media queries to adapt the layout to different screen sizes.
* **Consistent Branding:** Uses a consistent color palette, typography, buttons, and cards across the website.

> **Note:** Cargo tracking, shipping cost calculations, and contact form submissions are front-end demonstrations. Live tracking integrations, automatic cost calculations, and message delivery require additional functionality.

Cargo Link uses a clean, modern design intended to communicate trust, simplicity, and efficiency.


### Design Principles

* Simple and easy-to-understand navigation.
* Consistent colors and typography.
* Clear calls to action.
* Card-based layouts for presenting information.

##  Installation and Setup

To view and work on the project locally:

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd cargo-link
   ```

   Replace `cargo-link` with your actual folder name if it is different.

3. Open the folder in Visual Studio Code.

4. Open `index.html` in your browser, or use the Live Server extension in VS Code.

No backend setup is required to view the current front-end prototype.

##  Responsiveness

Cargo Link uses CSS media queries to adjust layouts for smaller screens.

The responsive design aims to ensure that:

* Navigation elements fit smaller screens.
* Cards stack vertically on mobile devices.
* Headings remain readable.
* Forms fit within the screen width.
* Buttons remain easy to use.
* Content does not overflow horizontally.
